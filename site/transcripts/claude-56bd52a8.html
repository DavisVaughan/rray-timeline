1	# Array slicing and extraction plan
2	
3	## Recommendation
4	
5	Use ordinary R subscripts for slicing and extraction:
6	
7	```r
8	rray_slice(x, ...)
9	rray_slice_assign(x, ..., value)
10	
11	rray_slice_axis(x, i, ..., axis)
12	rray_slice_assign_axis(x, i, ..., axis, value)
13	
14	rray_slice_rows(x, i)
15	rray_slice_assign_rows(x, i, value)
16	
17	rray_slice_columns(x, i)
18	rray_slice_assign_columns(x, i, value)
19	
20	rray_extract(x, i)
21	rray_extract_assign(x, i, value)
22	```
23	
24	`rray_slice()` performs dimension-preserving orthogonal selection across one
25	or more axes. It requires exactly one subscript per source axis, so `TRUE`
26	selects a whole axis. `rray_slice_axis()` performs the same operation on one
27	axis held in a variable, and `rray_slice_rows()` and `rray_slice_columns()`
28	are its first and second axis shortcuts. `rray_extract()` accepts flat
29	positions or coordinate points and always returns a one-dimensional array.
30	
31	Keep subscripts separate from integer coordinate arrays:
32	
33	| Property | Subscript | Coordinate array |
34	|---|---|---|
35	| Used by | `rray_slice()`, `rray_slice_axis()`, `rray_extract()` | `rray_index()`, `rray_index_axis()` |
36	| Meaning | A set of positions | One source coordinate per output point |
37	| Accepted forms | Integer, double, logical, character where defined, `NULL` | Bare integer vector or array |
38	| Negative values | Select the complement | Error |
39	| Zero | Ignored | Error |
40	| Shape | Does not connect positions across axes | Connects coordinates pointwise through broadcasting |
41	
42	The function name determines the contract. The dimensions of `i` never turn a
43	slice subscript into a coordinate array. `rray_extract()` has a separate,
44	explicit matrix rule for coordinate points.
45	
46	Do not add replacement functions. Every `_assign()` function returns a
47	modified copy of `x`. There are no `[` or `[[` methods because rray4 provides
48	functions rather than an array class.
49	
50	## The indexing family
51	
52	The complete family has five read operations:
53	
54	| Operation | Function | Result shape |
55	|---|---|---|
56	| Orthogonal subscripts | `rray_slice(x, ...)` | One output axis per source axis |
57	| One-axis subscript | `rray_slice_axis(x, i, ..., axis)` | Source dimensions with one axis replaced |
58	| First or second axis subscript | `rray_slice_rows(x, i)`, `rray_slice_columns(x, i)` | Source dimensions with one axis replaced |
59	| One-axis coordinate array | `rray_index_axis(x, i, ..., axis)` | Source dimensions with one axis replaced |
60	| Full coordinate arrays | `rray_index(x, ...)` | Common coordinate dimensions |
61	| Flat subscript or point matrix | `rray_extract(x, i)` | One dimensional |
62	
63	`rray_index()` is the general coordinate operation. Every other operation can
64	be described by constructing one explicit coordinate array for every source
65	axis and then calling `rray_index()`. The public wrappers remain important
66	because they accept different inputs, guarantee more specific shapes, retain
67	more names, and can use faster implementations.
68	
69	See `plans/index.md` for strict coordinate arrays and the complete lowering of
70	each operation to `rray_index()`.
71	
72	## Orthogonal slicing
73	
74	Each subscript controls one source axis. Subscripts are normalized separately,
75	then their locations form a Cartesian product.
76	
77	```r
78	x <- array(1:24, c(2, 3, 4))
79	
80	rray_slice(x, c(2, 1), c(3, 1), 2)
81	# dimensions: c(2, 2, 1)
82	
83	rray_slice_axis(x, c(3, 1), axis = 2)
84	# dimensions: c(2, 2, 4)
85	```
86	
87	This is close to base R's `x[..., drop = FALSE]`. Slicing never drops axes.
88	
89	The same Cartesian product can be expressed through full coordinate indexing.
90	After normalizing the three subscripts to positive locations, shape them as an
91	open mesh:
92	
93	```text
94	axis 1 coordinates: (I, 1, 1)
95	axis 2 coordinates: (1, J, 1)
96	axis 3 coordinates: (1, 1, K)
97	common dimensions:  (I, J, K)
98	```
99	
100	The shaped coordinate arrays broadcast to the slicing result dimensions.
101	
102	## `rray_slice()`
103	
104	```r
105	rray_slice(x, ...)
106	rray_slice_assign(x, ..., value)
107	```
108	
109	Each element of `...` applies to the matching source axis. `...` must contain
110	exactly one subscript per source axis. `TRUE` selects a whole axis.
111	
112	```r
113	rray_slice(x, 1, TRUE, TRUE)
114	# dimensions: c(1, 3, 4)
115	
116	rray_slice(x, TRUE, 1, TRUE)
117	# dimensions: c(2, 1, 4)
118	
119	rray_slice(x, TRUE, TRUE, TRUE)
120	# dimensions: c(2, 3, 4)
121	```
122	
123	Empty arguments are an error. Base R writes a whole axis as a gap between two
124	commas, which is easy to miscount and invisible on screen, so `rray_slice()`
125	asks for a value instead. The error should point at `TRUE` and at
126	`rray_slice_axis()`.
127	
128	```r
129	rray_slice(x, , , 1:2)
130	# Error: `...` must not contain empty arguments.
131	# Use `TRUE` to select a whole axis, or `rray_slice_axis()` for a single axis.
132	```
133	
134	Too few and too many subscripts are the same error. Subscripts in `...` must
135	be unnamed because selection is positional.
136	
137	Because every argument is an ordinary value, the dots are plain `list2()` dots
138	and splicing needs no special handling:
139	
140	```r
141	indices <- rep(list(TRUE), rray_dimensionality(x))
142	indices[[3]] <- c(3, 1)
143	rray_slice(x, !!!indices)
144	```
145	
146	`value` follows `...` in `rray_slice_assign()`, so it must be supplied by
147	name.

149	## `rray_slice_axis()`
150	
151	```r
152	rray_slice_axis(x, i, ..., axis)
153	rray_slice_assign_axis(x, i, ..., axis, value)
154	```
155	
156	The dots are empty and must stay empty. They force `axis` and `value` to be
157	supplied by name, so a call always says which axis it means and never reads as
158	a second subscript. This matches `rray_rep()` and `rray_split()`.
159	
160	```r
161	rray_slice_axis(x, c(3, 1), axis = 2)
162	rray_slice_assign_axis(x, c(3, 1), axis = 2, value = 0L)
163	```
164	
165	`rray_slice_axis()` has exactly the same subscript semantics as supplying `i`
166	at the matching position in `rray_slice()`. The same normalized subscript is
167	used for every lane through the selected axis. Only the selected axis
168	dimension can change.
169	
170	```r
171	x <- matrix(
172	  c(
173	    10, 20, 30, 40,
174	    50, 60, 70, 80
175	  ),
176	  nrow = 2,
177	  byrow = TRUE
178	)
179	
180	rray_slice_axis(x, c(4, 1), axis = 2)
181	#      [,1] [,2]
182	# [1,]   40   10
183	# [2,]   80   50
184	```
185	
186	The function replaces the need to pad a call with `TRUE` when `axis` is held
187	in a variable.
188	
189	`i` is always an ordinary subscript. Its dimensions do not affect the result
190	dimensions. A multidimensional object that is not a valid ordinary subscript
191	is an error. Use `rray_index_axis()` when an integer array supplies a different
192	location for different lanes.

12	#'   elements, zero is ignored, duplicates repeat elements, and `NA` gives a

34	#'
35	#' @export
36	#' @examples

//
// Useful when only modifying the attributes of an object,
// without touching the underlying data.
//
// - Read only accesses to the data are "passed through" to the wrapped object
// - Writable access forces a shallow duplication of the wrapped object if it
//   EVER looks shared, which happens if we are wrapping a basic R object
//   supplied from the R side by a user, or if we rewrap a wrapper's underlying
//   data (because the original wrapper also shares it).
r_obj* r_wrap(r_obj* x) {
  R_altrep_class_t cls = wrapper_class(r_typeof(x));

  // If `x` is a wrapper, unwrap it to gain access to the underlying data. This
  // is what we wrap and bump the reference count of. This avoids a
  // proliferation of wrappers. We manage writable access to the underlying data
  // by always cloning it before giving out a writable handle if it is ever

  r_obj* data = is_wrapper(x) ? wrapper_readonly(x) : x;

  r_attrib_clone_from(out, x);

#' Extract or assign values in an array
#'
#' `rray_extract()` selects values from `x` by 1D location or by coordinate
#' point. The result is always a 1D array.
#'
#' `rray_extract_assign()` replaces the selected values with `value` and returns
#' a modified copy of `x`.
#'
#' @details
#' The type and shape of `i` decide how it is used:
#'
#' - An integer or double vector holds 1D locations. `x` is treated as its
#'   equivalent flattened array, so location `4` in a 2 x 3 matrix is row 2,
#'   column 2. Locations follow the usual R rules: negative values drop
#'   elements, zero is ignored, duplicates repeat elements, and `NA` gives a
#'   missing value.
#'
#' - A logical vector must be size 1 or the size of `x`. A logical array must
#'   have the same dimensions as `x`, so `rray_extract(x, x > 5)` works. When
#'   `TRUE`, the corresponding value in `x` is returned.
#'
#' - An integer or double matrix holds coordinate points. Each row selects one
#'   element, and there must be one column per axis of `x`. Coordinates must be
#'   positive and within the dimension of their axis. `NA` at any position
#'   within the row generates a missing value.
#'
#' For raw arrays the missing value is `as.raw(0)`, and for list arrays it is
#' `NULL`.
#'
#' @section Assignment:
#' `rray_extract_assign()` selects values with the same rules, with one
#' exception: `i` can't contain missing values.
#'
#' `value` is cast to the type of `x`, then broadcast to the number of selected
#' values. It must be size 1 or have one element per selected value.
#'
#' When a value is selected more than once, the last assignment wins:
#'
#' ```r
#' rray_extract_assign(1:3, c(2, 2), c(10L, 20L))
#' #> [1]  1 20  3
#' ```
#'
#' @param x An array.
#'
#' @param i A numeric vector of locations, a logical vector, a logical array
#'   with the same dimensions as `x`, or a numeric matrix of coordinate points.
#'
#' @param value An array to assign to the selected values.
#'
#' @returns
#' - `rray_extract()` returns a one-dimensional array. Names are always dropped.
#'
#' - `rray_extract_assign()` returns `x` with the selected values replaced. The
#'   type, dimensions, and names of `x` are kept.
#'
#' @export
#' @examples
#' x <- array(1:24, c(2L, 3L, 4L))
#'
#' # 1D locations
#' rray_extract(x, c(1, 4, 24))
#'
#' # Negative locations drop elements
#' rray_extract(x, -(1:20))
#'
#' # A logical mask with the same dimensions as `x`
#' rray_extract(x, x %% 5 == 0)
#'
#' # One row per point, one column per axis
#' points <- rbind(
#'   c(1, 1, 1),
#'   c(2, 3, 4),
#'   c(1, 2, 3)
#' )
#' rray_extract(x, points)
#'
#' # Assign one value to every selected element
#' rray_extract_assign(x, x %% 5 == 0, 0L)
#'
#' # Or one value per selected element
#' rray_extract_assign(x, points, c(100L, 200L, 300L))

}

r_obj* rray_extract_assign(
  r_obj* x,
  r_obj* i,
  r_obj* value,
  struct rray_arg* x_arg,
  struct rray_arg* i_arg,
  struct rray_arg* value_arg,
  struct r_lazy error_call
) {
  check_unclassed(x, x_arg, error_call);
  x = KEEP(arg_as_array(x, x_arg, error_call));

  r_obj* dimensions = r_dim(x);
  const int dimensionality = rray_dimensionality_from_dimensions(dimensions);
  check_dimensionality(dimensionality);

  const struct rray_extract_subscript subscript = rray_as_extract_subscript(
    i,
    r_int_cbegin(dimensions),
    dimensionality,
    RRAY_SUBSCRIPT_MISSING_error,
    i_arg,
    error_call
  );
  KEEP(subscript.index);

  value = KEEP(rray_cast(value, x, value_arg, x_arg, error_call));

  r_obj* value_dimensions = r_dim(value);
  const int size = r_ssize_as_integer(subscript.size);

  check_broadcastable(
    r_int_cbegin(value_dimensions),
    rray_dimensionality_from_dimensions(value_dimensions),
    &size,
    1,
    value_arg,
    error_call
  );

  r_obj* out = KEEP(r_clone(x));

  switch (r_typeof(out)) {
  case R_TYPE_logical:
    rray_extract_assign_lgl(out, subscript, value);
    break;
  case R_TYPE_integer:
    rray_extract_assign_int(out, subscript, value);
    break;
  case R_TYPE_double:
    rray_extract_assign_dbl(out, subscript, value);
    break;
  case R_TYPE_complex:
    rray_extract_assign_cpl(out, subscript, value);
    break;
  case R_TYPE_raw:
    rray_extract_assign_raw(out, subscript, value);
    break;
  case R_TYPE_character:
    rray_extract_assign_chr(out, subscript, value);
    break;
  case R_TYPE_list:

How it works (src/extract-assign.c)

  1. Turn x into an array and read i with the shared rray_as_extract_subscript(), with missing values set to error.
  2. Cast value to the type of x with rray_cast().
  3. Check that value can broadcast to c(n), where n is the number of selected values. A scalar value is read with a step of 0, so it is never expanded to n elements.
  4. Copy x with r_clone() and write into the copy.

Everything that can fail runs before the copy. So an error never leaves a half-written result, and value can safely be x.

The typed cores take just (out, subscript, value). The points loop reads the dimensions from out, which keeps the type switch to one line per type. The mask loop stops as soon as every selected value is written.

The fix

  • Data only: src/wrapper.c already had a static r_clone_data() that copies the data and nothing else. I exposed it in src/wrapper.h.

  • Two attributes: the assign shell now builds out with r_clone_data(x), then sets dim and, when present, dimnames. This is the same pattern rray_cast() uses.

  • A side benefit: out is now always a fresh, plain vector. It no longer depends on the ALTREP wrapper to copy data on first write, and it can never share memory with value.

The same problem exists elsewhere, and I did not change it. I probed some other functions with an unclassed array that has attr(x, "foo") <- "bar". These keep foo:

  • rray_broadcast() when the dimensions already match (it returns x as is)

  • rray_cast() to the same type, and any cast of a bare vector

  • rray_set_dimensions()

  • rray_insert_axes()

  • rray_set_axis_names()

The cause is shared. r_wrap() copies every attribute with r_attrib_clone_from(), and vec_as_array() either returns x untouched or wraps it. Functions that allocate a fresh result, such as rray_broadcast() when it has to expand or rray_extract(), don't have the problem. Fixing it properly probably means r_wrap(), or a variant of it, keeping only dim and dimnames. That is a change across the package, so it should be a separate PR if you want it.
