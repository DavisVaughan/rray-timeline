1	# Rolling plan
2	
3	## Recommendation
4	
5	Add two functions:
6	
7	```r
8	rray_roll(x, ..., n, axes)
9	rray_roll_each(x, ..., n, axis)
10	```
11	
12	Both move elements along an axis. An element pushed off one end comes back on
13	the other.
14	
15	- `rray_roll()` rolls one or more axes, with one shift per axis. Every lane
16	  through an axis moves by the same amount, so each output position has exactly
17	  one source position, and names roll with the data.
18	
19	- `rray_roll_each()` rolls one axis, with one shift per lane. Lanes can move by
20	  different amounts, so an output position can come from different source
21	  positions in different lanes. Names on the rolled axis are always dropped.
22	
23	The split mirrors pairs the package already has:
24	
25	| Every lane moves together | Each lane moves on its own |
26	|---|---|
27	| `rray_slice_axis()` | `rray_index_axis()` |
28	| `rray_rep()` | `rray_rep_each()` |
29	| `rray_roll()` | `rray_roll_each()` |
30	
31	The function decides what happens to names. The size or values of `n` never do.
32	A caller who wants names kept calls `rray_roll()`.
33	
34	## Terms
35	
36	- **Lane.** One run of elements along the rolled axis, with every other
37	  coordinate held fixed. For a matrix and `axis = 2`, each row is a lane. For
38	  dimensions `(A, B, C)` and `axis = 2`, there are `A * C` lanes, each of
39	  length `B`.
40	
41	- **Lane dimensions.** The dimensions of `x` with the rolled axis set to 1. For
42	  `(A, B, C)` and `axis = 2`, they are `(A, 1, C)`. There is one lane per
43	  element of an array with these dimensions.
44	
45	- **Shift.** The value of `n` for one lane or one axis. It can be negative,
46	  zero, or larger than the dimension.
47	
48	## Shared rules
49	
50	### Direction
51	
52	A positive shift moves elements toward higher positions, as in NumPy:
53	
54	```r
55	rray_roll(1:5, n = 2, axes = 1)
56	# [1] 4 5 1 2 3
57	```
58	
59	A negative shift moves them toward lower positions:
60	
61	```r
62	rray_roll(1:5, n = -1, axes = 1)
63	# [1] 2 3 4 5 1
64	```
65	
66	### Wrapping
67	
68	A shift is reduced modulo the dimension `d` of the rolled axis, into `[0, d)`:
69	
70	```text
71	k = n mod d
72	out[..., j, ...] = x[..., (j - k) mod d, ...]
73	```
74	
75	So a shift of `7` on a dimension of `5` is a shift of `2`, and a shift of `-1`
76	is a shift of `4`:
77	
78	```r
79	rray_roll(1:5, n = 7, axes = 1)
80	# [1] 4 5 1 2 3
81	```
82	
83	A shift of `0`, or any multiple of `d`, leaves the axis unchanged.
84	
85	### Values of `n`
86	
87	- Integers, and anything that casts losslessly to integer. Doubles holding
88	  whole numbers work and `1.5` is an error. Logicals work too, with `TRUE` as
89	  `1`, the same as `axes` and `times` accept them today.
90	
91	- Any sign and any magnitude within the R integer range, which is
92	  `-2147483647` to `2147483647`. `-2147483648` is reserved for `NA`, and a
93	  double outside the range fails the cast.
94	
95	- No missing values.
96	
97	- No classed objects.
98	
99	### Zero dimensions
100	
101	When the rolled axis has dimension 0, there is nothing to move. Every shift is
102	valid, and it is still validated. The result equals `x`, with the names rule of
103	the function applied.
104	
105	### Bare vectors
106	
107	`x` goes through `arg_as_array()`, so a bare vector is a one-dimensional array
108	and its names move to `dimnames`. The result is always an array.
109	
110	## `rray_roll()`
111	
112	```r
113	rray_roll(x, ..., n, axes)
114	```
115	
116	### Arguments
117	
118	- `x`: an array or bare vector.
119	
120	- `...`: must be empty. It forces `n` and `axes` to be named, as in
121	  `rray_rep()`.
122	
123	- `n`: a bare integer vector of size 1 or the size of `axes`, validated the
124	  same way as `axes`. A size 1 `n` is used for every axis in `axes`. Otherwise
125	  `n[[i]]` is the shift for `axes[[i]]`. `n` can't have attributes, so names,
126	  dimensions, and classes are all errors. Arrays of per-lane shifts belong to
127	  `rray_roll_each()`.
128	
129	- `axes`: a bare integer vector of axes. Required, with no default. Any order.
130	  An axis can't appear twice. `integer()` is allowed and rolls nothing.
131	
132	The result has the type, dimensions, and dimensionality of `x`.
133	
134	### Worked examples
135	
136	#### One dimension
137	
138	```r
139	rray_roll(1:5, n = 2, axes = 1)
140	# [1] 4 5 1 2 3
141	
142	rray_roll(1:5, n = -1, axes = 1)
143	# [1] 2 3 4 5 1
144	
145	rray_roll(1:5, n = 7, axes = 1)
146	# [1] 4 5 1 2 3
147	
148	rray_roll(1:5, n = 0, axes = 1)
149	# [1] 1 2 3 4 5
150	```
151	
152	Each result is a one-dimensional array with dimensions `5`.
153	
154	#### A matrix
155

159	  nrow = 2,
160	  dimnames = list(c("r1", "r2"), c("a", "b", "c"))
161	)
162

164	#    a b c
165	# r1 1 3 5
166	# r2 2 4 6
167	```

173	#    c a b
174	# r1 5 1 3

178	#    b c a

static r_obj* rray_rep_impl(

  int axis,
  bool each,
  struct rray_arg* arg,

  check_unclassed(x, arg, error_call);
  x = KEEP(arg_as_array(x, arg, error_call));

  r_obj* dimensions = r_dim(x);
  const int* v_dimensions = r_int_cbegin(dimensions);
  const int dimensionality = rray_dimensionality_from_dimensions(dimensions);
  check_dimensionality(dimensionality);

  check_axis(axis, dimensionality, rray_args.axis, error_call);
  const int axis_dimension = v_dimensions[axis - 1];

  times = KEEP(
    arg_as_times(times, each ? axis_dimension : 1, rray_args.times, error_call)
  );
  const int* v_times = r_int_cbegin(times);
  const r_ssize times_size = r_length(times);

  const int out_dimension =
    rray_rep_dimension(axis_dimension, v_times, times_size, error_call);

  r_obj* out_dimensions = KEEP(r_alloc_integer(dimensionality));
  int* v_out_dimensions = r_int_begin(out_dimensions);
  r_memcpy(v_out_dimensions, v_dimensions, sizeof(int) * dimensionality);
  v_out_dimensions[axis - 1] = out_dimension;

  const r_ssize out_size = rray_size_from_dimensions_checked(
    v_out_dimensions,
    dimensionality,
    error_call
  );

  r_obj* out = KEEP(r_alloc_vector(r_typeof(x), out_size));
  r_attrib_poke_dim(out, out_dimensions);

  r_ssize block_size = 1;
  for (int i = 0; i < axis - 1; ++i) {
    block_size *= v_dimensions[i];
  }

  if (!each) {
    block_size *= axis_dimension;
  }

  r_ssize n_groups = 1;
  for (int i = axis; i < dimensionality; ++i) {
    n_groups *= v_dimensions[i];
  }

  const r_ssize n_blocks_per_group = each ? axis_dimension : 1;

  if (times_size == 1) {
    // Groups flatten away with uniform `times`
    const int times = v_times[0];
    const r_ssize n_blocks = n_groups * n_blocks_per_group;
    rray_rep_fill_uniform(x, out, block_size, n_blocks, times);
  } else {
    rray_rep_fill_varying(
      x,
      out,
      block_size,
      n_blocks_per_group,
      n_groups,
      v_times
    );
  }

  r_obj* out_names = KEEP(rray_rep_names(
    r_dim_names(x),
    axis,
    out_dimension,
    each,
    v_times,
    times_size
  ));
  if (out_names != r_null) {
    r_attrib_poke_dim_names(out, out_names);
  }

  FREE(5);
  return out;
}

static r_ssize fill_arg_buffer(
  struct rray_arg* arg,
  char* buf,
  r_ssize cur_size,
  r_ssize tot_size
) {

    if (cur_size < 0) {

Type dispatch in rray4 is written as an exhaustive `switch`, following vctrs'
`vec_typeof2()` and `vec_ptype2_switch_native()`. Build a symmetric combined

`rray_reduction_ptype()` and their promotion tables.

**How to apply:** Pair the switch with an exhaustive test. `helper-ptype.R` has

}

  r_obj* n,
  r_ssize axes_size,

static r_no_return void stop_roll_n_size(
  r_ssize n_size,
  r_ssize axes_size,
  struct rray_arg* arg,
  struct r_lazy error_call
) {
  if (axes_size == 1) {
    r_abort_lazy_call(
      error_call,
      "%s must be size 1, not size %" R_PRI_SSIZE ".",
      rray_arg_format(arg),
      n_size
    );
  } else {
    r_abort_lazy_call(
      error_call,
      "%s must be size 1 or size %" R_PRI_SSIZE " to match `axes`, "
      "not size %" R_PRI_SSIZE ".",
      rray_arg_format(arg),
      axes_size,
      n_size
    );
  }
}

static r_obj* rray_roll_locations(int dimension, int shift) {
  r_obj* out = KEEP(r_alloc_integer(dimension));
  int* v_out = r_int_begin(out);

  for (int j = 0; j < dimension; ++j) {
    v_out[j] = (j >= shift) ? j - shift + 1 : j - shift + dimension + 1;
  }

  FREE(1);
  return out;
}

static void check_roll_n_not_missing(
  r_obj* n,
  struct rray_arg* arg,
  struct r_lazy error_call
) {
  const r_ssize n_size = r_length(n);
  const int* v_n = r_int_cbegin(n);

  for (r_ssize i = 0; i < n_size; ++i) {
    if (v_n[i] == r_globals.na_int) {
      r_abort_lazy_call(
        error_call,
        "%s must not contain missing values.",
        rray_arg_format(arg)
      );
    }
  }
}

static inline int rray_roll_shift(int n, int dimension) {
  if (dimension == 0) {
    return 0;
  }

  int out = n % dimension;

  if (out < 0) {
    out += dimension;
  }

  return out;
}

#' @description
#' `rray_roll()` shifts the elements of `x` along one or more axes, with one

#'
#' @details

#' shift moves them toward the start. Shifts wrap around, so a shift of 7 along
#' an axis with dimension 5 is the same as a shift of 2. A shift of 0, or any
#' multiple of the dimension, leaves the axis unchanged.
#'

#'

#'   shift for `axes[[i]]`.

#'   can appear at most once.
#'
#' @returns
#' An array with the same type and dimensions as `x`.
#'
