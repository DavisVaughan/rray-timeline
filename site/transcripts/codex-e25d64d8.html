   type and vector type to happen outside the loop. Running through
   the indices in column-major order also improves cache locality. */

  int dimensionality,

Assessing ALTREP handling

rray4 also avoids a full vector of flattened locations. Its difference from base R is that it precomputes an offset for each selected position on each axis, then reuses those offsets while copying the result.

Here is the path through rray_slice() and slice.c:

  1. Each subscript is checked and normalized. TRUE means the whole axis, character values are matched to axis names, zeroes are removed, and negative values become a selection of the remaining positions. See slice-subscript.c.
  2. rray4 fills one buffer with the selected zero-based positions, one segment per axis. Missing positions get a sentinel value. It uses these positions to select dimnames. See location filling and name selection.
  3. It multiplies each position by that axis’s stride. For dim(x) = c(2, 3, 4) and subscripts c(2, 1), c(3, 1), 2, the three offset segments are [1, 0], [4, 0], and [6].
  4. It starts at 4 + 6, reads the first-axis run at offsets 11, 10, advances the second axis, then reads at 7, 6. Those are values 12, 11, 8, 7. The copy loop updates the outer-axis sum between runs.
