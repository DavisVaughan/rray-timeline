     1	#' Slice an array
     2	#'
     3	#' @description
     4	#' `rray_slice()` selects positions along each axis of `x`. The result always
     5	#' has the same dimensionality as `x`.
     6	#'
     7	#' `rray_slice_axis()` selects positions along a single `axis` of `x`. Every
     8	#' other axis is kept whole. `rray_slice_rows()` and `rray_slice_columns()` are
     9	#' shortcuts for `axis = 1` and `axis = 2`.
    10	#'
    11	#' The `_assign` versions replace the selected positions with `value` and
    12	#' return a modified copy of `x`.
    13	#'
    14	#' @details
    15	#' `NA` in a subscript gives missing values in the result. For raw arrays the
    16	#' missing value is `as.raw(0)`, and for list arrays it is `NULL`. If the axis
    17	#' has names, the name of a missing value is `""`. For assignment, `NA` in a
    18	#' subscript leaves `x` unchanged at that position but uses one element of
    19	#' `value`.
    20	#'
    21	#' Unlike `[`, an empty argument does not select a whole axis. Use `TRUE`
    22	#' instead, so that every axis is provided explicitly:
    23	#'
    24	#' ```r
    25	#' x <- array(1:24, c(2L, 3L, 4L))
    26	#'
    27	#' # Base R
    28	#' x[1, , , drop = FALSE]
    29	#'
    30	#' # rray
    31	#' rray_slice(x, 1, TRUE, TRUE)
    32	#' ```
    33	#'
    34	#' When the axis is held in a variable, use `rray_slice_axis()` rather than
    35	#' padding a call to `rray_slice()` with `TRUE`:
    36	#'
    37	#' ```r
    38	#' # These are the same
    39	#' rray_slice(x, TRUE, TRUE, c(4, 1))
    40	#' rray_slice_axis(x, c(4, 1), axis = 3)
    41	#' ```
    42	#'
    43	#' @param x An array.
    44	#'
    45	#' @param ... For `rray_slice()` and `rray_slice_assign()`, one unnamed
    46	#'   subscript for each axis of `x`, in axis order. Each subscript is one of:
    47	#'
    48	#'   - `TRUE`, to select the whole axis.
    49	#'
    50	#'   - A logical vector the size of the axis. `TRUE` selects a position.
    51	#'
    52	#'   - An integer or double vector of locations. Negative values drop
    53	#'     positions, zero is ignored, and duplicates repeat positions.
    54	#'
    55	#'   - A character vector of names, matched against the names of the axis. The
    56	#'     first match is used when names are duplicated.
    57	#'
    58	#'   - `NULL`, to select nothing.
    59	#'
    60	#'   For `rray_slice_axis()` and `rray_slice_assign_axis()`, these dots must be
    61	#'   empty.
    62	#'
    63	#' @param i A subscript for the selected axis. It takes any of the forms
    64	#'   allowed in `...`.
    65	#'
    66	#' @param axis A single integer. The axis to slice along.
    67	#'
    68	#' @param value An array to assign to the selected positions. It is cast to
    69	#'   the type of `x`, then broadcast to the dimensions of the selection. Those
    70	#'   are the dimensions of the matching read, like `rray_slice(x, ...)` for
    71	#'   `rray_slice_assign()`.
    72	#'
    73	#' @returns
    74	#' - `rray_slice()`, `rray_slice_axis()`, `rray_slice_rows()`, and
    75	#'   `rray_slice_columns()` return an array with the same type and
    76	#'   dimensionality as `x`. The dimension of each axis is the number of
    77	#'   positions selected on it. The names of each axis are selected along with
    78	#'   the values.
    79	#'
    80	#' - The `_assign` versions return `x` with the selected positions replaced.
    81	#'   The type, dimensions, and names of `x` are kept.
    82	#'
    83	#' @export
    84	#' @examples
    85	#' x <- array(1:24, c(2L, 3L, 4L))
    86	#'
    87	#' # The first row
    88	#' rray_slice(x, 1, TRUE, TRUE)
    89	#'
    90	#' # Reorder and repeat positions
    91	#' rray_slice(x, c(2, 1, 2), 1, 4)
    92	#'
    93	#' # Drop positions with negative locations
    94	#' rray_slice(x, TRUE, -2, -(1:2))
    95	#'
    96	#' # Select by name
    97	#' y <- array(1:6, c(2L, 3L), dimnames = list(c("a", "b"), c("c", "d", "e")))
    98	#' rray_slice(y, "b", c("e", "c"))

#' Slice an array
#'
#' @description
#' `rray_slice()` selects positions along each axis of `x`. The result always
#' has the same dimensionality as `x`.
#'
#' `rray_slice_assign()` replaces the selected positions with `value` and
#' returns a modified copy of `x`.
#'
#' @details
#' `NA` in a subscript gives missing values in the result. For raw arrays the
#' missing value is `as.raw(0)`, and for list arrays it is `NULL`. If the axis
#' has names, the name of a missing value is `""`. For assignment, `NA` in a
#' subscript leaves `x` unchanged at that position but uses one element of
#' `value`.
#'
#' Unlike `[`, an empty argument does not select a whole axis. Use `TRUE`
#' instead, so that every axis is provided explicitly:
#'
#' ```r
#' x <- array(1:24, c(2L, 3L, 4L))
#'
#' # Base R
#' x[1, , , drop = FALSE]
#'
#' # rray
#' rray_slice(x, 1, TRUE, TRUE)
#' ```
#'
#' @param x An array.
#'
#' @param ... One unnamed subscript for each axis of `x`, in axis order. Each
#'   subscript is one of:
#'
#'   - `TRUE`, to select the whole axis.
#'
#'   - A logical vector the size of the axis. `TRUE` selects a position.
#'
#'   - An integer or double vector of locations. Negative values drop
#'     positions, zero is ignored, and duplicates repeat positions.
#'
#'   - A character vector of names, matched against the names of the axis. The
#'     first match is used when names are duplicated.
#'
#'   - `NULL`, to select nothing.
#'
#' @param value An array to assign to the selected positions. It is cast to
#'   the type of `x`, then broadcast to the dimensions of the selection, which
#'   are the dimensions of `rray_slice(x, ...)`.
#'
#' @returns
#' - `rray_slice()` returns an array with the same type and dimensionality as
#'   `x`. The dimension of each axis is the number of positions selected on
#'   it. The names of each axis are selected along with the values.
#'
#' - `rray_slice_assign()` returns `x` with the selected positions replaced.
#'   The type, dimensions, and names of `x` are kept.
#'
#' @export
#' @examples
#' x <- array(1:24, c(2L, 3L, 4L))
#'
#' # The first row

#'
#' # Reorder and repeat positions
#' rray_slice(x, c(2, 1, 2), 1, 4)
#'
#' # Drop positions with negative locations

#' # Select by name

#' Slice an array
#'
#' @description
#' `rray_slice()` selects positions along each axis of `x`. The result always
#' has the same dimensionality as `x`.
#'
#' `rray_slice_axis()` is `rray_slice()` restricted to a single axis, which can
#' be more ergonomic to write. `rray_slice_rows()` and `rray_slice_columns()`
#' are shortcuts for `axis = 1` and `axis = 2`.
#'
#' The `_assign` versions replace the selected positions with `value` and
#' return a modified copy of `x`.
#'
#' @details
#' `NA` in a subscript gives missing values in the result. For raw arrays the
#' missing value is `as.raw(0)`, and for list arrays it is `NULL`. If the axis
#' has names, the name of a missing value is `""`. For assignment, `NA` in a
#' subscript leaves `x` unchanged at that position but uses one element of
#' `value`.
#'
#' Unlike `[`, an empty argument does not select a whole axis. Use `TRUE`
#' instead, so that every axis is provided explicitly:
#'
#' ```r
#' x <- array(1:24, c(2L, 3L, 4L))
#'
#' # Base R
#' x[1, , , drop = FALSE]
#'
#' # rray
#' rray_slice(x, 1, TRUE, TRUE)
#'
#' # Or, more simply
#' rray_slice_axis(x, 1, axis = 1)
#' rray_slice_rows(x, 1)
#' ```
#'
#' @param x An array.
#'
#' @param ... One unnamed subscript for each axis of `x`, in axis order. Each
#'   subscript is one of:
#'
#'   - `TRUE`, to select the whole axis.
#'
#'   - A logical vector the size of the axis. `TRUE` selects a position.
#'
#'   - An integer or double vector of locations. Negative values drop
#'     positions, zero is ignored, and duplicates repeat positions.
#'
#'   - A character vector of names, matched against the names of the axis. The
#'     first match is used when names are duplicated.
#'
#'   - `NULL`, to select nothing.
#'
#'   For `rray_slice_axis()` and `rray_slice_assign_axis()`, these dots must be
#'   empty.
#'
#' @param i A subscript for the selected axis. It takes any of the forms
#'   allowed in `...`.
#'
#' @param axis A single integer. The axis to slice along.
#'
#' @param value An array to assign to the selected positions. It is cast to
#'   the type of `x`, then broadcast to the dimensions of the selection.
#'
#' @returns
#' - `rray_slice()`, `rray_slice_axis()`, `rray_slice_rows()`, and
#'   `rray_slice_columns()` return an array with the same type and
#'   dimensionality as `x`. The dimension of each axis is the number of
#'   positions selected on it. The names of each axis are selected along with
#'   the values.
#'
#' - The `_assign` versions return `x` with the selected positions replaced.
#'   The type, dimensions, and names of `x` are kept.
#'
