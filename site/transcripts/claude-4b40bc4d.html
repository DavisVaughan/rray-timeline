  const int out = x < y ? y : x;

Why base max() wins along axis 1

  • The slow case is older than this branch. Along axis 1 (or over all axes) every element updates the same running result, so each step waits on the one before it. Before this branch that case was already 16.6ms, so 3x slower than base. The NA check made it 6x.

  • Base R uses branches instead. Its loop says "if this value is bigger, keep it", which almost never fires, so the CPU guesses right and runs ahead. Our branch-free selects are what make the other cases vectorize, but here they force the CPU to wait on every element.

  • NaN doesn't change the picture much. With 1% NaN mixed in, base only slows from 5.7ms to 6.5ms.
