1	# Repeat an array along an axis
2	
3	## Status
4	
5	This document is an implementation plan. It does not describe code that is
6	already present.
7	
8	The target branch is `feature/rep`, based on `main`.
9	
10	## Goal
11	
12	Add two functions:
13	
14	```r
15	rray_rep(x, times, axis)
16	rray_rep_each(x, times, axis)
17	```
18	
19	They are the array versions of `vctrs::vec_rep()` and `vctrs::vec_rep_each()`.
20	vctrs repeats along the size of a vector. rray4 repeats along one axis of an
21	array, so both gain a required `axis`.
22	
23	`rray_rep()` repeats the whole axis. `rray_rep_each()` repeats each slice of
24	the axis.
25	
26	```r
27	x <- array(1:6, c(3, 2))
28	
29	rray_rep(x, 2, axis = 1)      # (6, 2), rows 1,2,3,1,2,3
30	rray_rep_each(x, 2, axis = 1) # (6, 2), rows 1,1,2,2,3,3
31	```
32	
33	For reference, the numpy names:
34	
35	- `np.repeat(x, n, axis = k)` is `rray_rep_each()`.
36	
37	- `rray_rep()` has no numpy name. The closest is
38	  `np.concatenate([x] * n, axis = k)`.
39	
40	- `np.tile()` is a separate multi axis function. It is not part of this plan,
41	  see "Out of scope".
42	
43	## Decision summary
44	
45	- Both functions take a single `axis`. It is required and has no default, which
46	  matches `rray_split()`, `rray_remove_axes()`, and `rray_permute_axes()`.
47	
48	- `axis` must be between 1 and the dimensionality of `x`. Out of range is an
49	  error. These functions never add an axis, that is what `rray_broadcast()` is
50	  for.
51	
52	- `times` comes before `axis`, so `vec_rep()` habits carry over.
53	
54	- Names repeat alongside the data, so the repeated axis can come back with
55	  duplicate names. Names belong to a slice, not to a position, and this is what
56	  `vec_rep()` does.
57	
58	- Type is preserved. Nothing is cast, and there is no `ptype` argument.
59	
60	- The copy needs no broadcasting and no strided iterator. It is a loop of
61	  contiguous block copies, see "Implementation".
62	
63	## Public behavior
64	
65	### `rray_rep()`
66	
67	`rray_rep()` repeats the whole `axis` of `x`, `times` times. `times` is a single
68	non-missing whole number greater than or equal to 0.
69	
70	The dimension along `axis` becomes `dimension * times`. Every other axis is
71	unchanged.
72	
73	```text
74	[3, 2] with times = 2 along axis 1 -> [6, 2]
75	[3, 2] with times = 2 along axis 2 -> [3, 4]
76	```
77	
78	```r
79	x <- array(1:6, c(3, 2))
80	
81	rray_rep(x, 2, axis = 1)
82	#>      [,1] [,2]
83	#> [1,]    1    4
84	#> [2,]    2    5
85	#> [3,]    3    6
86	#> [4,]    1    4
87	#> [5,]    2    5
88	#> [6,]    3    6
89	```
90	
91	### `rray_rep_each()`
92	
93	`rray_rep_each()` repeats each slice of `axis` in place. `times` is a vector of
94	non-missing whole numbers greater than or equal to 0, recycled to the dimension
95	along `axis`, so it is either size 1 or exactly that dimension.
96	
97	The dimension along `axis` becomes `sum(times)`. Every other axis is unchanged.
98	
99	```r
100	x <- array(1:6, c(3, 2))
101	
102	rray_rep_each(x, 2, axis = 1)
103	#>      [,1] [,2]
104	#> [1,]    1    4
105	#> [2,]    1    4
106	#> [3,]    2    5
107	#> [4,]    2    5
108	#> [5,]    3    6
109	#> [6,]    3    6
110	
111	rray_rep_each(x, c(1, 2, 3), axis = 1)
112	#>      [,1] [,2]
113	#> [1,]    1    4
114	#> [2,]    2    5
115	#> [3,]    2    5
116	#> [4,]    3    6
117	#> [5,]    3    6
118	#> [6,]    3    6
119	```
120	
121	With `times` of size 1 the two functions differ only in the order of the
122	result. `rray_rep()` gives `1,2,3,1,2,3` and `rray_rep_each()` gives
123	`1,1,2,2,3,3`.
124	
125	### Names
126	
127	Names repeat with the data. The repeated axis keeps its names in the repeated
128	order, and every other axis keeps its names untouched.
129	
130	```r
131	x <- array(1:6, c(3, 2), dimnames = list(c("a", "b", "c"), c("x", "y")))
132	
133	rray_names(rray_rep(x, 2, axis = 1))
134	#> [[1]]
135	#> [1] "a" "b" "c" "a" "b" "c"
136	#>
137	#> [[2]]
138	#> [1] "x" "y"
139	
140	rray_names(rray_rep_each(x, 2, axis = 1))
141	#> [[1]]
142	#> [1] "a" "a" "b" "b" "c" "c"
143	#>
144	#> [[2]]
145	#> [1] "x" "y"
146	```
147	
148	Duplicate names are expected and are not deduplicated or repaired.
149	
150	If `x` has no names at all, the result has none. If `x` has names but the
151	repeated axis has `NULL` names, that axis stays `NULL` and the other axes keep
152	their names.
153	
154	### Type
155	
156	The result has the same type as `x`. All seven vector types are supported:
157	logical, integer, double, complex, character, raw, and list.
158	
159	Classed input is rejected by `check_unclassed()`, as everywhere else in the
160	package.
161	
162	### Shape of the result
163	
164	A bare vector is treated as a 1D array and comes back as a 1D array, which is
165	what the rest of the package does.
166	
167	```r
168	rray_rep(1:3, 2, axis = 1)
169	#>  int [1:6(1d)] 1 2 3 1 2 3
170	```
171	
172	### Zero and empty cases
173	
174	`times = 0` is allowed and gives a dimension of 0 along `axis`.
175	
176	```text
177	[3, 2] with times = 0 along axis 1 -> [0, 2]
178	```
179	
180	If the dimension along `axis` is already 0, `times` must be size 0 or size 1 to
181	recycle, and the result keeps a dimension of 0.
182	
183	For `rray_rep_each()`, individual zeros drop individual slices.
184	
185	```r
186	rray_rep_each(array(1:3, 3), c(1, 0, 2), axis = 1)
187	#>  int [1:3(1d)] 1 3 3
188	```

r_obj* rray_rep(
  r_obj* x,
  r_obj* times,
  int axis,
  bool each,
  struct rray_arg* arg,
  struct r_lazy error_call
) {
  check_unclassed(x, arg, error_call);
  x = KEEP(arg_as_array(x, arg, error_call));

  r_obj* dimensions = r_dim(x);
  const int* v_dimensions = r_int_cbegin(dimensions);
  const int dimensionality = rray_dimensionality_from_dimensions(dimensions);
  check_dimensionality(dimensionality);

  check_axis(axis, dimensionality, rray_args.axis, error_call);
  const int dimension = v_dimensions[axis - 1];

  times = KEEP(arg_as_times(
    times,
    each ? dimension : 1,
    rray_args.times,
    error_call
  ));
  const int* v_times = r_int_cbegin(times);

  const int out_dimension =
    rray_rep_dimension(dimension, each, v_times, error_call);

  r_obj* out_dimensions = KEEP(r_alloc_integer(dimensionality));
  int* v_out_dimensions = r_int_begin(out_dimensions);
  r_memcpy(v_out_dimensions, v_dimensions, sizeof(int) * dimensionality);
  v_out_dimensions[axis - 1] = out_dimension;

  const r_ssize out_size = rray_size_from_dimensions_checked(
    v_out_dimensions,
    dimensionality,
    error_call
  );

  r_obj* out = KEEP(r_alloc_vector(r_typeof(x), out_size));
  r_attrib_poke_dim(out, out_dimensions);

  r_ssize inner = 1;
  for (int i = 0; i < axis - 1; ++i) {
    inner *= v_dimensions[i];
  }

  r_ssize outer = 1;
  for (int i = axis; i < dimensionality; ++i) {
    outer *= v_dimensions[i];
  }

  if (each) {
    rray_rep_copy(x, out, inner, dimension, outer, v_times);
  } else {
    rray_rep_copy(x, out, inner * dimension, 1, outer, v_times);
  }

  r_obj* out_names = KEEP(rray_rep_names(
    r_dim_names(x),
    axis,
    out_dimension,
    each,
    v_times
  ));
  if (out_names != r_null) {
    r_attrib_poke_dim_names(out, out_names);
  }

  FREE(5);
  return out;
}

static r_obj* arg_as_times(
  r_obj* times,
  r_ssize size,
  struct rray_arg* arg,
  struct r_lazy error_call
) {
  times = KEEP(arg_as_non_negative_bare_integer(times, arg, error_call));

  const r_ssize times_size = r_length(times);

  if (times_size == size) {
    FREE(1);
    return times;
  }

  if (times_size != 1) {
    stop_times_size(times_size, size, arg, error_call);
  }

  const int elt = r_int_get(times, 0);

  r_obj* out = KEEP(r_alloc_integer(size));
  int* v_out = r_int_begin(out);

  for (r_ssize i = 0; i < size; ++i) {
    v_out[i] = elt;
  }

  FREE(2);
  return out;
}

#' @description
#' - `rray_rep()` repeats the whole `axis` of `x`, `times` times. The dimension

      indices <- lapply(x_dimensions, seq_len)
      indices[[axis]] <- starts[[i]] + seq_len(dimensions[[i]])
      do.call(`[`, c(list(x), indices, list(drop = FALSE)))

  r_obj* times,
  r_ssize size,
