# `r_wrap()` starts with no attributes

Today `r_wrap(x)` copies every attribute of `x` onto the new wrapper. This
plan makes the wrapper start with no attributes, so each caller sets exactly
the ones it wants.

The work is one pull request. It lands before `plans/view.md`, so this plan
still uses the current `wrapper` names.

---

# Why

## Stray attributes leak through

Functions that go through `r_wrap()` keep any attribute the input happens to
carry. Functions that allocate a new result drop them. So two reshapes of the
same input disagree:

```r
x <- array(1:4, c(2, 2))
attr(x, "foo") <- 1
names(x) <- letters[1:4]

attributes(rray_set_dimensions(x, c(4L, 1L)))
#> $dim: 4 1
#> $foo: 1
#> $names: "a" "b" "c" "d"

attributes(rray_permute_axes(x, 2:1))
#> $dim: 2 2
```

`rray_insert_axes()` keeps `foo` and `names` the same way. `class` can't leak,
because `check_unclassed()` rejects classed input first.

After this plan, every function above returns only `dim` and, when there are
any, `dimnames`.

## Every caller only wants `dim` and `dimnames`

All 9 callers of `r_wrap()` set `dim`, `dimnames`, or both, and nothing else.
Two of them spend extra work undoing the copy: `rray_set_dimensions()` clears
`dimnames`, and `vec_as_array()` clears `names`.

## No pairlist copy

`r_attrib_clone_from()` allocates a copy of the attribute pairlist on every
call. A wrapper with no attributes skips that.

## Nothing relies on the copy

No test outside `test-wrapper.R` checks that a stray attribute survives, and
no C code reads an attribute other than `dim` or `dimnames` off the result of
`arg_as_array()`.

---

# Out of scope

Some paths return `x` itself, so stray attributes still pass through them.
This plan leaves them alone. A later plan can decide whether they should also
return a view with only `dim` and `dimnames`:

- `vec_as_array()` when `x` already has `dim`.

- `rray_clear_titles()` and `rray_clear_axis_title()` when there are no
  titles to clear.

- `rray_cast()` when `x` and `to` have the same type, through
  `vec_as_array()`.

---

# A note on order

`Rf_setAttrib()` refuses to set `dimnames` on an object with no `dim`. Every
caller that sets `dimnames` must set `dim` first. The names and titles setters
used to get `dim` for free from the copy, so they now set it themselves from
`r_dim(x)`.

---

#include "clone.h"

// Wrap an R object's data in a read-only ALTREP wrapper
//
// Useful when ONLY modifying the attributes of the new object, and NEVER the
// underlying data.
//
// The ALTREP wrapper itself is immediately marked as immutable with
// `MARK_NOT_MUTABLE()`. This is extremely important! It ensures that R won't
// ever ask for a writable `DATAPTR()` without first calling `Duplicate()`.
//
// Note that R will VERY often use `REAL()` instead of `REAL_RO()` when it only
// needs a read-only pointer. This is due to `REAL_RO()` being a newer idea that
// was only introduced with ALTREP, and a lot of historical code hasn't been
// ported over. Because of that, our `DATAPTR()` ALTREP methods must return a
// pointer even in the `writable` case, but we expect that R (and all packages)
// hold up their side of the bargain by only actually writing to this pointer
// when they fully own it or when there are `NO_REFERENCES()`, which won't be
// the case since we've used `MARK_NOT_MUTABLE()`. The `NO_REFERENCES()` case is
// relevant for `x + y + 1` where R will attempt to reuse `x + y`'s temporary
// result since there aren't any other owners. We don't want
// `rray_set_dimensions(x) + 1` to look reusable!
r_obj* r_wrap(r_obj* x) {
  R_altrep_class_t cls = wrapper_class(r_typeof(x));

  // If `x` is a wrapper, unwrap it to gain access to the original data and wrap
  // that instead. This avoids a proliferation of nested wrappers. Refcounts on
  // `x` itself should also still be correct - each wrapper looks like an
  // individual user of `x`.
  r_obj* data = is_wrapper(x) ? wrapper_data(x) : x;

  // Reference count on `data` is bumped when we wrap it here.
  // It now looks at least "referenced", but not necessarily "shared".
  r_obj* out = KEEP(R_new_altrep(cls, data, r_null));

  // Creates a fresh attribute pairlist!
  // Note that we always use `x` here, not `data`.
  r_attrib_clone_from(out, x);

  // The all important immutable marking of `out`, preventing any downstream C
  // code from requesting a writable pointer without duplicating first.
  MARK_NOT_MUTABLE(out);

  FREE(1);
  return out;
}

static inline bool is_wrapper(r_obj* x) {
  if (!ALTREP(x)) {
    return false;

      rray_arg_format(arg),
      x_dimensionality
    );
  }

  check_dimensionality(dimensionality);

  r_obj* out_dimensions = KEEP(r_alloc_integer(dimensionality));
  int* v_out_dimensions = r_int_begin(out_dimensions);
  r_memcpy(v_out_dimensions, v_x_dimensions, sizeof(int) * x_dimensionality);

  for (int i = x_dimensionality; i < dimensionality; ++i) {

  r_attrib_poke_dim(out, out_dimensions);

    r_obj* out_names = KEEP(r_alloc_list(dimensionality));
