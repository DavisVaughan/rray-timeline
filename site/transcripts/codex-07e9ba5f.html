Thinking

Framing missing-value arithmetic behavior

Probably not, if rray_add() is elementwise. na_rm fits a reduction such as rray_sum(), where missing elements can be skipped. In elementwise addition, each output position still needs a value. Making NA + 3 return 3 would treat NA as zero, which is a different operation.

I’d keep missing values propagating in rray_add() and let callers replace missing values with zero explicitly when that is what they mean.
