# Titles plan

## Goal

Every function that takes one array and returns one array should keep the
titles of `x` wherever its axes keep their meaning. Titles are the names on
the dimnames list:

```r
x <- array(1:24, c(2, 3, 4), dimnames = list(A = c("a", "b"), B = NULL, C = NULL))

rray_titles(x)
# [1] "A" "B" "C"
```

Binary and n-ary functions are out of scope until we settle how names combine
across inputs. See [Out of scope](#out-of-scope).

## Rules

These were decided up front and apply to every step.

- A title labels an axis, not its positions. An axis that keeps its identity
  keeps its title, even when it loses its names. `rray_sum(x, axes = 2)` keeps
  title `"B"` on axis 2.

- The result has a titles vector exactly when `x` has one. A new axis gets
  the title `""`. An all `""` titles vector is never turned into `NULL`. This
  matches `rray_set_axis_title(x, axis, NULL)`, which already leaves `""` in
  place.

- Titles can exist with no axis names at all. The dimnames list is then all
  `NULL` elements, like `list(A = NULL, B = NULL)`. Every helper must handle
  this case, which is the main trap: most names helpers only allocate their
  output list when some axis has names.

- A function that drops all names drops all titles. Today that is
  `rray_extract()`, `rray_index()`, and `rray_set_dimensions()`.

- `rray_set_names(x, names)` replaces the whole dimnames list. The names of
  `names` become the titles of `x`, so an unnamed list drops them and `NULL`
  clears everything.

- `rray_broadcast()` is left alone for now, see [Out of scope](#out-of-scope).

## Implementation pattern

Each step adds titles to an existing names helper rather than adding a new
code path. The pattern is the same everywhere:

1. Read `x_titles = r_names(x_names)` next to the existing `x_names`. It is
   protected through `x`.

2. If `x_titles != r_null`, allocate the output names list up front instead of
   lazily, so a titles-only input still gets a list.

3. Either reuse `x_titles` unchanged (when the result has the same axes as
   `x`) or build an `out_titles` character vector in the same loop that builds
   the output names (when axes move, appear, or disappear).

4. Poke the titles onto the output list with `r_attrib_poke_names()`.

`r_alloc_character()` fills with `""`, so new axes need no explicit poke.

Per the `AGENTS.md` protection review, `out_titles` is allocated while the
output list is live, so `KEEP()` it until it is poked onto the list.

### 1. Slice names

`rray_slice_names()` in `src/slice.c` covers every function built on
`rray_slice()`:

- `rray_slice()`

- `rray_slice_axis()`, `rray_slice_rows()`, `rray_slice_columns()`

- `rray_reverse()`

- `rray_roll()`

- `rray_rep()`, `rray_rep_each()`

Slicing never adds, removes, or moves axes, so the titles of `x` are reused
unchanged. `rray_slice_names()` takes `x_names` instead of `v_x_names` and
pokes `r_names(x_names)` onto its output. It already allocates its output
whenever `x_names` exists, so the titles-only case needs no extra work.

```r

r_obj* rray_split(
  r_obj* x,
  int axis,
  r_obj* dimensions,
  struct rray_arg* arg,
  struct r_lazy error_call
) {
  check_unclassed(x, arg, error_call);
  x = KEEP(arg_as_array(x, arg, error_call));

  r_obj* x_dimensions = KEEP(rray_dimensions(x, arg, error_call));
  const int* v_x_dimensions = r_int_cbegin(x_dimensions);
  const int dimensionality = rray_dimensionality_from_dimensions(x_dimensions);
  check_dimensionality(dimensionality);

  check_axis(axis, dimensionality, rray_args.axis, error_call);
  const int axis_dimension = v_x_dimensions[axis - 1];

  dimensions = KEEP(arg_as_non_negative_bare_integer(
    dimensions,
    rray_args.dimensions,
    error_call
  ));
  check_split_dimensions(
    dimensions,
    axis_dimension,
    rray_args.dimensions,
    error_call
  );
  const int* v_dimensions = r_int_cbegin(dimensions);

  // i.e. each array is the same dimension and splits `axis` evenly
  const bool uniform = r_length(dimensions) == 1;

  const r_ssize out_size =
    uniform ? axis_dimension / v_dimensions[0] : r_length(dimensions);

  r_obj* out = KEEP(r_alloc_list(out_size));

  r_obj* x_names = r_dim_names(x);
  r_obj* const* v_x_names = (x_names == r_null) ? NULL : r_list_cbegin(x_names);

  r_obj* x_axis_names = (v_x_names == NULL) ? r_null : v_x_names[axis - 1];
  r_obj* const* v_x_axis_names =
    (x_axis_names == r_null) ? NULL : r_chr_cbegin(x_axis_names);

  r_ssize v_x_strides[RRAY_MAX_DIMENSIONALITY];
  rray_fill_strides_from_dimensions(
    v_x_dimensions,
    dimensionality,
    v_x_strides
  );
  const r_ssize x_axis_stride = v_x_strides[axis - 1];

  const enum r_type type = r_typeof(x);

  // Initialized on the first iteration. Changes any time the output dimension
  // along `axis` changes, but in the uniform case all arrays share the same
  // dimensions object!
  r_obj* out_elt_dimensions = r_null;
  r_keep_loc out_elt_dimensions_loc;
  KEEP_HERE(out_elt_dimensions, &out_elt_dimensions_loc);

  struct rray_run_iterator it;

  int previous_dimension = -1;

  // The location along the axis. For example, with a 2x10 array split along
  // columns this runs from 0-9. The `x_axis_stride` maps it to `x_start`, a
  // flat location into `x` itself.
  int x_axis_start = 0;

  for (r_ssize i = 0; i < out_size; ++i) {
    const int dimension = uniform ? v_dimensions[0] : v_dimensions[i];

    if (dimension == previous_dimension) {
      rray_run_iterator_reset1(&it);
    } else {
      previous_dimension = dimension;

      out_elt_dimensions = r_alloc_integer(dimensionality);
      KEEP_AT(out_elt_dimensions, out_elt_dimensions_loc);
      int* v_out_elt_dimensions = r_int_begin(out_elt_dimensions);
      r_memcpy(
        v_out_elt_dimensions,
        v_x_dimensions,
        sizeof(int) * dimensionality
      );
      v_out_elt_dimensions[axis - 1] = dimension;

      rray_run_iterator_init1(
        &it,
        v_out_elt_dimensions,
        dimensionality,
        v_x_strides
      );
    }

    r_obj* out_elt = r_alloc_vector(type, rray_run_iterator_size(&it));
    r_list_poke(out, i, out_elt);
    r_attrib_poke_dim(out_elt, out_elt_dimensions);

    const r_ssize x_start = x_axis_start * x_axis_stride;
    rray_split_fill(x, out_elt, x_start, &it);

    if (v_x_axis_names != NULL) {
      r_obj* out_elt_names = KEEP(rray_split_elt_names(
        v_x_names,
        dimensionality,
        axis,
        v_x_axis_names,
        x_axis_start,
        dimension
      ));
      r_attrib_poke_dim_names(out_elt, out_elt_names);
      FREE(1);
    } else if (x_names != r_null) {
      r_attrib_poke_dim_names(out_elt, x_names);
    }

    x_axis_start += dimension;
  }

  FREE(5);
  return out;
}

static void check_split_dimensions(
  r_obj* dimensions,
  int axis_dimension,
  struct rray_arg* arg,
  struct r_lazy error_call
) {
  const r_ssize size = r_length(dimensions);
  const int* v_dimensions = r_int_cbegin(dimensions);

  if (size == 1) {
    const int dimension = v_dimensions[0];

    if (dimension == 0) {
      r_abort_lazy_call(
        error_call,
        "A single %s value must be positive, not 0.",
        rray_arg_format(arg)
      );
    }

    if (axis_dimension % dimension != 0) {
      r_abort_lazy_call(
        error_call,
        "A single %s value of %d must evenly divide the `axis` dimension "
        "of %d.",
        rray_arg_format(arg),
        dimension,
        axis_dimension
      );
    }
  } else {
    r_ssize total_dimension = 0;

    for (r_ssize i = 0; i < size; ++i) {
      total_dimension += v_dimensions[i];
    }

    if (total_dimension != axis_dimension) {
      r_abort_lazy_call(
        error_call,
        "%s must sum to the `axis` dimension of %d, not %" R_PRI_SSIZE ".",
        rray_arg_format(arg),
        axis_dimension,
        total_dimension
      );
    }
  }
}
